Fonctionnalites

Tout ce qu’il faut, rien de plus

○

Barre de menus uniquement

Memo vit dans votre barre de menus. Pas d’icone dans le Dock, pas de fenetre — toujours disponible, jamais dans le chemin.

△

Raccourci global

Mode toggle : appuyez sur ⌥ Espace pour demarrer, rappuyez pour arreter. Ou passez en push-to-talk dans les Preferences. Entierement personnalisable.

◆

Precision Whisper

Propulse par le modele gpt-4o-mini-transcribe d’OpenAI. Rapide, precis et multilingue dans plus de 18 langues.

■

Presse-papiers instantane

Apres la transcription, le texte va directement dans le presse-papiers. Pas de fenetre, pas d’etape supplementaire — ⌘V ou vous voulez.

●

Historique des transcriptions

Chaque transcription est sauvegardee localement et consultable. Retrouvez n’importe quelle dictee depuis la barre de menus.

△

Cle API securisee

Votre cle API OpenAI est stockee dans le Trousseau macOS — jamais en clair, jamais sur le disque sans protection.

Comment ca marche

Trois etapes, du micro au texte

1

Telecharger et installer

Telechargez le DMG, glissez Memo dans Applications, et lancez-le. Une icone micro apparait dans votre barre de menus.

2

Ajouter votre cle API OpenAI

Ouvrez les Preferences Memo depuis la barre de menus et collez votre cle API OpenAI. Elle est sauvegardee dans le Trousseau immediatement.

3

Appuyez sur ⌥ Espace et parlez

Appuyez sur le raccourci pour demarrer l’enregistrement, parlez, puis rappuyez pour arreter. Memo transcrit et copie le texte dans votre presse-papiers. ⌘V pour coller.
